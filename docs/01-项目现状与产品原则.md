# 项目现状与产品原则

## 1. 项目定位

Fund Valuation iOS 是一个面向个人持仓查看的 SwiftUI App。当前同时覆盖两类资产：

- A 股基金：查看基金实时估值、净值、当日盈亏、累计盈亏和业绩走势。
- 美股股票：手动维护美股持仓，查看行情、现价、成本价、当日盈亏、累计盈亏和 K 线。

App 的核心目标不是交易，也不是投顾平台，而是替代需要频繁登录、验证、人脸识别的银行/券商 App，提供一个打开即可查看持仓状态的轻量看板。

## 2. 当前能力

| 模块 | 当前能力 |
|---|---|
| 账号系统 | 邮箱注册/登录、退出登录、注销账号、邮箱验证码找回密码 |
| 基金持仓 | 新增、编辑、删除、本地缓存、登录后同步、重复基金覆盖 |
| 基金行情 | 天天基金估值、东方财富 pingzhong/F10 净值、沪深300对比走势 |
| 美股持仓 | 新增、编辑、删除、本地缓存、登录后同步、重复股票覆盖 |
| 美股行情 | Finnhub、Alpha Vantage、THS Bridge、Mock Provider |
| 美股搜索 | 按当前 Provider 搜索股票代码和名称 |
| K 线 | 美股 K 线缓存、区间切换优先复用已有更长区间数据 |
| 汇总 | 基金资产和美股资产分别展示，不做人民币/美元合并 |
| 设置 | 主题、AI 配置、美股数据源配置 |
| AI 分析 | 当前仅面向基金组合 |

## 3. 产品原则

### 3.1 持仓盈亏优先

首页和详情页的信息优先级固定为：

1. 资产规模。
2. 当日盈亏。
3. 累计盈亏。
4. 当前价/净值、成本价、更新时间、数据源。

不要把解释性文案、装饰图标或头像放到主要视觉层级。

### 3.2 基金和美股独立

基金和美股的市场、币种、交易时间和数据源不同：

- 基金使用人民币。
- 美股使用美元。
- 不做基金和美股合并总资产。
- 不做汇率换算。
- 刷新频率按资产类型分开。

### 3.3 展示真实状态，不制造实时幻觉

行情数据可能延迟、失败或来自缓存。所有行情页面必须能表达：

- 当前市场状态：交易中、盘前、盘后、休市、未知。
- 最新更新时间。
- 数据源。
- 是否显示旧数据。

失败时保留旧数据，不把价格置为 0，不清空列表。

### 3.4 操作一致

基金和美股都应遵守同一套操作心智：

- 顶部全局刷新。
- 首页 Banner 右下角添加按钮。
- 列表点击进详情。
- 详情页右上角编辑。
- 编辑页支持保存、取消、删除。
- 重复添加时以第二次录入为准。

### 3.5 视觉不过度装饰

当前用户明确不接受“液态玻璃”方向，也不希望大面积泛灰、浮夸渐变或股票头像。后续视觉调整只允许在现有信息结构上做层级、色彩、间距、圆角和状态反馈优化，不改变列表内容结构。

## 4. 非目标

当前阶段不做：

- 银行/券商账户登录。
- 自动同步真实交易持仓。
- 下单交易。
- 投资建议强提示。
- 基金和美股总览混合。
- 股票头像/logo。
- 大面积营销式首页。
