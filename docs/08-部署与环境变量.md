# 部署与环境变量

## 1. 后端部署（Zeabur）

### 1.1 首次部署

1. 推送代码到 GitHub，关联 Zeabur 项目。
2. Zeabur 自动检测 `ths-bridge/Dockerfile` 并构建。
3. 部署完成后获得域名，如 `https://thsbridge.zeabur.app`。
4. 将域名填写到 `AppEnvironment.swift` 的 `productionBackendURL`。

### 1.2 环境变量

| 变量 | 必填 | 说明 | 示例 |
|---|---|---|---|
| `JWT_SECRET` | 是 | JWT 签名密钥，生产环境必须改为随机字符串 | `openssl rand -hex 32` 生成 |
| `SMTP_HOST` | 找回密码必填 | SMTP 服务器地址 | `smtp.gmail.com` |
| `SMTP_PORT` | 否 | SMTP 端口，默认 587 | `587` |
| `SMTP_USER` | SMTP 必填 | SMTP 登录邮箱 | `your@gmail.com` |
| `SMTP_PASS` | SMTP 必填 | SMTP 密码/应用专用密码 | 见下方说明 |
| `SMTP_FROM` | 否 | 发件地址，默认同 SMTP_USER | — |
| `DATABASE_URL` | 否 | 数据库连接，默认 SQLite | `sqlite:///app/data/ths_bridge.db` |
| `BRIDGE_ACCESS_TOKEN` | 否 | 美股行情接口可选鉴权 | 随机字符串 |

### 1.3 SMTP 配置说明

找回密码需要 SMTP 发送验证码邮件。推荐邮箱配置：

#### Gmail
1. 开启两步验证：https://myaccount.google.com/security
2. 生成应用专用密码：https://myaccount.google.com/apppasswords
3. 填入环境变量（保留密码中的空格）

#### QQ邮箱
1. 设置 → 账户 → 开启 POP3/SMTP 服务
2. 生成授权码
3. `SMTP_HOST=smtp.qq.com`，`SMTP_PASS=授权码`

#### 163邮箱
1. 设置 → POP3/SMTP → 开启
2. 新增授权码
3. `SMTP_HOST=smtp.163.com`，`SMTP_PASS=授权码`

未配置 SMTP 时，验证码会打印到 Zeabur 日志中，可用于调试。

### 1.4 持久化存储

SQLite 数据库存储在容器内，重启会丢失数据。使用 Zeabur Volume：

1. Zeabur → Storage → Add Volume
2. Mount Path: `/app/data`
3. 设置环境变量 `DATABASE_URL=sqlite:///app/data/ths_bridge.db`

## 2. 数据库

### 2.1 默认

使用 SQLite，自动在 `ths-bridge/` 目录创建 `ths_bridge.db`。

### 2.2 表结构

| 表 | 说明 |
|---|---|
| `users` | 用户（邮箱、bcrypt 密码哈希、软删除） |
| `password_reset_codes` | 重置码（SHA-256 哈希、10 分钟过期、5 次尝试上限） |
| `fund_positions` | 基金持仓（user_id + fund_code 唯一约束） |
| `stock_positions` | 美股持仓（user_id + symbol 唯一约束） |

### 2.3 清空数据

停止后端，删除 `ths_bridge.db` 文件，重新启动即可。

## 3. 本地开发

```bash
cd ths-bridge
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8787 --reload
```

模拟器连接 `http://127.0.0.1:8787`，后端地址硬编码无需配置。
找回密码验证码会打印在终端日志中。

## 4. 构建与发布

### 4.1 构建前检查

- `AppEnvironment.swift` 中的 `productionBackendURL` 是否为 Zeabur 真实域名
- Xcode 切换为 Release（Any iOS Device）构建
- 确认登录注册页面不出现"账号服务"面板
- 确认设置页没有后端 URL 和行情供应商配置入口

### 4.2 发布清单

- [ ] 后端已部署 Zeabur，`/health` 返回正常
- [ ] `JWT_SECRET` 已设为随机字符串
- [ ] SMTP 已配置（如需找回密码功能）
- [ ] `productionBackendURL` 已更新为实际域名
- [ ] Release 构建编译通过
- [ ] 完整走一遍注册→登录→找回密码流程
