后端服务已从 iOS 仓库拆分到独立项目：

```text

```

当前生产 Zeabur 服务已切换到独立后端项目作为代码仓库来源。iOS 仓库中的 `ths-bridge/` 仅保留迁移说明，不再作为部署源。

iOS、Web 和未来 Android 继续使用相同生产域名和 `/v1/*` API：

```text
https://thsbridge.zeabur.app
```

## 1. 后端部署

后端部署、环境变量、数据库、SMTP、Zeabur Docker 构建和 `/health` 检查以独立后端项目的 README 为准。

关键生产要求：

| 项 | 要求 |
|---|---|
| `JWT_SECRET` | 必须设置为固定强随机字符串；变更会让旧 token 全部失效 |
| `DATABASE_URL` | 必须指向持久化数据库；SQLite 需挂载 Zeabur Volume |
| `TWELVE_DATA_API_KEY` | 可选，用于美股 OTC/缺口兜底 |
| `SMTP_*` | 找回密码发邮件时配置；未配置时仅用于调试日志 |
| CORS | 需允许 Web 生产域名和本地开发端口 |

推荐 SQLite 持久化配置：

```text
DATABASE_URL=sqlite:////app/data/ths_bridge.db
```

## 2. iOS 端配置

Release 构建中后端地址仍写死在 `AppEnvironment.swift`：

```swift
static var productionBackendURL: String {
    "https://thsbridge.zeabur.app"
}
```

`thsBridgeURL` 与 `productionBackendURL` 保持同源。账号、持仓、基金行情、美股行情都经由同一后端。

Debug 构建如需连本地后端，可临时把上述地址改为本地服务地址；不要把调试 URL 暴露到设置页。
